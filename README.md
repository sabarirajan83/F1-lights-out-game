# 🏎️ F1 Lights Out Game

**"And it's lights out and away we go!"** 🏁

Test your reaction speeds against the world's fastest drivers. This project is a simple, high-precision reaction time game based on the Formula 1 starting light sequence.

## 🚀 Live Demo
You can play the game right now here:
👉 **[View Live Demo](https://sabarirajan83.github.io/F1-lights-out-game/)**

## 🕹️ How to Play

1.  **Preparation:** Click the **Start** button to begin the sequence.
2.  **Anticipation:** Watch as the five red lights turn on one by one. 🔴 🔴 🔴 🔴 🔴
3.  **Reaction:** The lights will go out at a random interval. As soon as they vanish, **CLICK** or **TAP** the screen immediately! 💨
4.  **The Result:** Your reaction time will be displayed in milliseconds. Can you beat the 200ms average of an F1 driver? ⏱️

> ⚠️ **Jump Start!** If you click before the lights go out, your start will be invalidated. Stay focused!

---

## ✨ Features

* 🚦 **Realistic Timing:** Uses a random delay for the lights-out moment, just like a real Grand Prix.
* ⚡ **Millisecond Precision:** Accurate tracking of your tap/click response.
* 📱 **Responsive Design:** Fully playable on desktops, tablets, and smartphones.
* 🎨 **F1 Aesthetics:** Dark UI with the iconic red-to-black transition.

---

## 🛠️ Tech Stack

* **HTML5** - Semantic structure.
* **CSS3** - Layout and smooth light animations.
* **JavaScript (ES6)** - Timing logic and event handling.

## 📥 Installation & Local Development

If you want to host this locally or modify the code:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/sabarirajan83/F1-lights-out-game.git
    ```
2.  **Navigate to the project folder:**
    ```bash
    cd F1-lights-out-game
    ```
3.  **Open the game:**
    Simply open `index.html` in any modern web browser.
